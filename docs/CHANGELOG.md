# 變更紀錄

## 2026-10-09　交易系統展示圖小標改為中性文字

**問題描述**
交易系統 6 張展示圖右側的小標寫「實際運行中的交易系統」，與其他作品呈現方式不一致，看起來仍在特別區分。

**根本原因**
展示圖原本是為出任務平台製作，小標強調「實際運行」；網站沿用同一組圖片。

**修改內容**
- `images/showcase/real-trading/1~6.png`：網站版小標改為「台指期＆BTC 程式交易系統」，遮蔽範圍與畫面內容不變。
- 出任務用的版本（`exports/`，不上傳 GitHub）保留原小標。

## 2026-10-09　移除「實際作品」標章，作品統一呈現

**問題描述**
「✔ 實際作品」標章與底部「其餘為示範作品」的說明，讓其他作品看起來像假的，降低整體可信度。

**根本原因**
上一版為了區分交易系統與其他作品，加了標章，底部說明也明確寫出示範作品。

**修改內容**
- `js/showcase.js`：移除卡片與燈箱的「實際作品」標章渲染。
- `js/showcase-data.js`：移除 `isReal` 欄位與型別說明；交易系統描述刪除「（非示範畫面）」。
- `index.html`：移除 `#lightboxReal`；底部說明改為「※ 作品畫面以範例資料呈現，功能與風格皆可依需求客製。」；CSS `v=6`、showcase-data.js 與 showcase.js `v=4`。
- `css/style.css`：移除 `.showcase-real` 樣式。

## 2026-10-09　作品展示新增實際作品「台指期＆BTC 程式交易系統」

**問題描述**
作品展示牆全部都是示範作品，缺少真實案例；使用者實際開發並運行中的交易系統（Line_Chat_Test 專案）沒有放上網站。

**根本原因**
初版展示牆只為示範作品設計：圖片路徑固定為 `.svg`、資料結構沒有區分示範與實際作品，底部說明也寫死「以上為示範作品」。

**修改內容**
- `images/showcase/real-trading/1~6.png`：交易系統 GUI 實際截圖，合成為 1600×1000 展示圖。因為會公開在網路上，以下內容皆已模糊處理：帳號、姓名、登入環境、持倉與損益、實單／live 模式標示、五支策略名稱與規則說明、BTC 策略參數、跟單帳號與設定、回測策略標題與績效。
- `js/showcase-data.js`：
  - `buildScreens()` 新增第三個參數 `ext`（預設 `svg`），實際截圖用 `png`。
  - `ShowcaseItem` 新增選填欄位 `isReal`，`true` 時顯示「實際作品」標章。
  - 新增作品 `real-trading`（分類：程式與自動化），排在全部作品最前面。
  - 移除示範作品 `auto-trading`（量化交易策略回測系統），由實際作品取代；圖片與 `tools/showcase/automation_pages.py` 產生器保留，需要時可加回。
- `js/showcase.js`：卡片封面左下角與燈箱標題區顯示「✔ 實際作品」標章。
- `index.html`：燈箱新增 `#lightboxReal` 標章；底部說明改為區分實際作品與示範作品；CSS `v=5`、showcase-data.js 與 showcase.js `v=3`。
- `css/style.css`：新增 `.showcase-real` 綠色標章樣式。

## 2026-10-09　新增本機匯出資料夾 exports/（不上傳 GitHub）

**問題描述**
為了上架「出任務」專家作品，需要把作品展示的 SVG 轉成 PNG（平台只收 .jpg / .png）。轉出的圖片原本放在專案外的 `D:\ClaudeCode\` 底下，使工作目錄變得雜亂。

**根本原因**
匯出檔沒有固定的存放位置；第一次批次轉檔時，路徑跳脫字元處理錯誤，也在上層目錄留下殘檔（已清除）。

**修改內容**
- 新增 `exports/` 作為本機匯出資料夾，目前內容為 `exports/出任務作品圖/`（5 件作品、25 張 1600×1000 PNG，檔名開頭的數字即上傳順序）。
- `.gitignore`：加入 `exports/`，匯出檔只留在本機，不上傳 GitHub。

## 2026-10-04（晚上）　作品展示改為左側分類欄、暫時隱藏作品集區

**問題描述**
1. 作品展示副標過長（「…，每件作品都有 5 個畫面可以看」）。
2. 「作品集」區目前沒有正式案例，內容空洞。
3. 分類篩選按鈕橫排在上方，希望改成左側分類、右側作品的版面。

**根本原因**
初版版面以置中橫排篩選設計；作品集區固定顯示且每次載入都會讀取 Firebase。

**修改內容**
- `index.html`：
  - 刪除副標中「，每件作品都有 5 個畫面可以看」。
  - 作品展示改為 `.showcase-layout`：左側 `<aside class="showcase-sidebar">`（分類清單＋「找不到想要的類型？聊聊你的需求」連結），右側作品卡片。
  - 作品集區與導覽列「作品集」連結預設加上 `hidden`。
  - CSS 版本號 `v=4`、app.js 版本號 `v=6`。
- `js/app.js`：新增 `SHOW_PORTFOLIO_SECTION = false` 開關與 `applySectionVisibility()`；關閉時不顯示作品集區、不讀取 Firestore 作品資料。**未來有正式作品時，將此開關改為 `true` 即可恢復**（後台新增／編輯功能皆保留）。
- `css/style.css`：
  - 展示區最大寬度放寬為 1280px；左欄 210px，捲動時固定在畫面上（sticky）。
  - 分類按鈕改為直排清單樣式，數量靠右。
  - 860px 以下改為上下排列，分類變成可左右滑動的橫向膠囊列；並以 `minmax(0, 1fr)` 修正手機版欄寬被分類列撐開、卡片超出螢幕的問題。

## 2026-10-04（下午）　作品展示擴充：每件 5 個畫面、新增架站平台與進階遊戲

**問題描述**
每件作品只有一張圖，業主看不出完整功能；缺少 Shopify、WooCommerce、WordPress 等常見架站平台作品；遊戲類只有休閒小遊戲，展現不出較複雜的開發能力。

**根本原因**
初版展示牆以「一件作品一張圖」設計，資料結構只有單一 `image` 欄位，燈箱也只能顯示單張圖片。

**修改內容**
- 圖片改為每件作品一個資料夾：`images/showcase/<作品代碼>/1~5.svg`，共 18 件、90 張（舊的單張圖已移除）。
- 新增作品：
  - 架站平台：Shopify 品牌電商、WooCommerce 茶行商店、WordPress 室內設計官網
  - 遊戲設計：台灣 16 張麻將（多人連線）、集換式卡牌對戰、戰棋策略 RPG
- 原有 12 件作品各補到 5 個畫面（例如電商加上商品列表、商品頁、購物車、會員中心；遊戲加上標題畫面、地圖、角色選擇、結算等）。
- `tools/gen_showcase.py` 改為主程式，可指定只產生某件作品（`python tools/gen_showcase.py game-mahjong`）；繪圖程式拆分到 `tools/showcase/`：
  - `common.py` 共用元件（按鈕、表格、圖表、手機外框、人物頭像等）
  - `web_pages.py`、`platforms.py`、`automation_pages.py`、`bot_pages.py`、`games_casual_pages.py`、`games_advanced.py` 各類作品畫面
  - `web.py`、`automation.py`、`bots.py`、`games_casual.py` 保留初版的封面畫面
- `js/showcase-data.js`：資料結構由 `image` 改為 `screens: [{src, caption}]`，以 `buildScreens()` 依作品代碼產生路徑；新增「架站平台」分類。
- `js/showcase.js`：卡片顯示封面＋4 張小縮圖與「5 個畫面」標示，點小縮圖可直接開到該畫面；燈箱支援切換畫面（← →）、切換作品（↑ ↓ 或按鈕）、縮圖列與畫面說明。
- `index.html`：燈箱加入畫面說明、縮圖列、上一個／下一個作品按鈕；更新區塊副標與 JS／CSS 快取版本號。
- `css/style.css`：新增卡片小縮圖、畫面數標籤、燈箱縮圖列等樣式。
- 修正：LINE 對話示範圖中「10/05（日）」改為正確的「10/05（一）」。
- `.gitignore`：加入 `__pycache__/`、`*.pyc`。

## 2026-10-04　新增「作品展示」圖片牆

**問題描述**
網站作品集只有三張純文字卡片，內容單薄，業主無法直觀看出可承接的專案類型與完成度，不利接案。

**根本原因**
作品集僅由 Firebase 讀取文字資料（圖示 + 描述），沒有任何作品畫面；也缺少網頁、遊戲等類別的展示。

**修改內容**
- `images/showcase/*.svg`：新增 12 張示範作品介面圖（800×500），分四類
  - 網頁設計：咖啡廳形象官網、電商購物網站、營運數據後台
  - 程式與自動化：Excel 自動化月報表、多平台比價爬蟲、量化交易回測系統、桌面版庫存管理系統
  - 聊天機器人：LINE 官方帳號自動客服、Discord 社群機器人
  - 遊戲設計：2D 平台跳躍、寶石消除益智、太空射擊
- `tools/gen_showcase.py`：產生上述 SVG 的腳本（僅用標準函式庫），要調整圖片內容時修改後重新執行即可。
- `js/showcase-data.js`：作品資料設定檔（分類、標題、簡介、功能重點、技術標籤、委託連結），新增或修改作品只需改此檔。
- `js/showcase.js`：展示牆渲染、分類篩選、點擊放大燈箱（支援左右切換、鍵盤 ← → / Esc）。不依賴 Firebase，資料庫連線失敗時展示牆仍可正常顯示。
- `index.html`：導覽列新增「作品展示」連結；Hero 次要按鈕改為「看看作品」；於 Hero 與免費工具之間新增 `#showcase` 區塊與燈箱；CSS 加上快取版本號 `?v=2`。
- `css/style.css`：新增作品展示牆、分類按鈕、卡片懸停效果、燈箱與手機版樣式。
- 展示區底部加註「示範作品介面」說明，避免業主誤認為已交付的客戶案例。
